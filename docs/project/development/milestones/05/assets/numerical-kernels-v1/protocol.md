# Numerical-kernel investigation protocol
Preserve the exact 191-file ten-optimisation control. Investigate generated precise compute_89 PTX and sm_89 SASS, driver-loaded resources and theoretical occupancy. No privileged settings, driver, registry or security changes. Hardware counters may be unavailable; static analysis is not dynamic attribution.

PC through ssh pc only for performance. All requests start new simulations: device 0, block 128, refinement 4, eight Jacobi iterations, 480 unpaced steps, 8000 and 110592 particles both with/without XSPH .01 and confinement .1. Existing scenes/configs and checkpoint schedule (0,1,120,240,480 at small size, none at large size). Completed-step clocks include host validation, transfers, submission, waits, cancellation and acceptance; setup/teardown, audits and output excluded. Profiles separate from primary timing. No build/test overlap with timed runs.

One hypothesis at a time in private exports. First test explicit invariant-coefficient hoisting, retaining precise operations and check precedence at original use sites. One warmup and two alternating exploratory pairs per workload. Reject adverse/unjustified variants; retain all results. If justified, qualify full release suite, explicitly selected CUDA tests, boundary/execution tests, Clippy, formatting, native ASan/UBSan, device checks and seven exact regression sizes before primary one warmup and five alternating pairs per workload (first measured candidate/control). Compare every physical/configuration/diagnostic output exactly, excluding measurements/build_revision only. GPU profiles across all four complete trajectories; source/PTX/binary/input identities before/after. Assess engineering value and consistency, not an automatic significance rule. Document unsuccessful experiments.

Cancellation/rollback/errors must preserve existing semantics and tests. Never change floating-point order, precision, support, solver work or fast-math flags. Revert only task-owned deltas if rejected; all ten pre-existing optimisations remain. No commits/tags/branches/pushes/gitlink changes.
