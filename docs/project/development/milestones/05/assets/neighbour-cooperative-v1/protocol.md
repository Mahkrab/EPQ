## Spatially grouped tiled traversal hypothesis

Source inspection also identifies an independent layout mismatch: current count/
fill schedule is spatial, but tiled storage and numerical traversal group rows by
identity. Once identities disperse, adjacent lanes gather unrelated positions and
padding follows unrelated degrees. Compare spatially grouped tiles with an inverse
identity-to-row map in the same unused sort scratch. Logical rows, identity-sorted
members and all arithmetic remain fixed. Both storage and traversal must change
together; the previously rejected spatial-only scheduling trial used compact CSR
and did not coalesce membership in spatial order. This hypothesis also reduces
padding if neighbouring spatial rows have similar lengths. No new allocation is
needed: offset bytes plus inverse ranks fit the existing 32*padded scratch half.
Use the same preflight/exploratory/final measurement policy, independently from the
cooperative trial. Do not combine candidates until each independently earns it.

## Exact per-membership geometry reuse

Both cooperative discovery and spatially grouped tiles regressed complete viewer
throughput and are rejected. One final independent prototype follows the source's
remaining immutable-position reuse opportunity. Density already calculates Poly6
weight and Spiky direction; its higher-identity squared suffix and the following
correction recalculate them before any position update. Cache exactly those rounded
values in a 16-byte record per physical membership slot, with an inactive sentinel.
Keep the identity-tiled layout and use the cache only in the grouped Jacobi path
at tiled sizes; standalone components and compact small inputs retain their path.
Preserve expression/error priority, original sums, pressure calculation and all
whole-grid/cancellation boundaries. Store cache records after indices in the same
checked neighbour allocation; required bytes rise from 4 to 20 per padded slot.
This is distinct from the rejected nine-column integer lookup cache and prior
register-only gradient-prefix reuse. Do not infer a gain from fewer operations.
Preflight the CUDA components, then the same warm-up/two exploratory pairs. Reject
on an unhelpful complete result; no further cache widths, sorting or cooperative
variants are authorised by this experimental protocol. A survivor must pass the
full final measurement and qualification programme above.
